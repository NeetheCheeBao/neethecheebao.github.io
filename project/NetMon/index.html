四条出口分别看什么

  • 国内测试 — 走中国站点（speedtest.cn / ipip），通常是直连 ISP。
  • 国外测试 — 未被墙的境外站点，规则里常叫「漏网之鱼」。
  • Cloudflare ProxyIP — 访问 CF CDN 时的落地 IP。
  • 墙外测试 X.com — 访问 X 的路径，切换节点时最容易变。
